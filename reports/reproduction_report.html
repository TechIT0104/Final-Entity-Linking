Generated from existing run artifacts in results/. No new LLM inference was executed for this report.

What was asked (paper-aligned goals)

Goal Reproduce the paper best settings and expected output folders.

Goal Run all datasets and produce final results.

Goal Evaluate honestly and compare with the paper table.

Constraint Local Windows machine is CPU-only.

Constraint GPU server is shared and can be contended.

What we did (implementation and evaluation)

  • Implemented a full rerun driver that follows the paper best settings and produces outputs in results/<DATASET>/<RUN_NAME>/.
  • Added resumability and incremental output writing to the prompting scripts to prevent lost progress on interruptions.
  • Added a strict evaluation mode (micro-F1 on gold mentions) alongside the legacy paper metric.
  • Generated two honest summary tables: best-settings comparison and all-runs scan.

Problems encountered and how we solved them

  • Broken torchvision::nms import error due to a mismatched torch/torchvision install. Fix: remove torchvision from the LLM env and re-validate transformers pipeline import.
  • Conda/pip environment drift (missing requests/idna) after removals. Fix: reinstall missing deps via python -m pip in the active env or recreate a clean env.
  • GPU contention and OOM on shared RTX 5000 Ada. Fix: resume-capable runs, plus optional memory caps via MHEL_MAX_GPU_MEM and MHEL_MAX_CPU_MEM.
  • Long runtimes under contention. Fix: allow safe stop/restart without losing progress by writing output.csv incrementally.

Evaluation method

Paper/legacy score: precision-like tp/(tp+fp) computed on joined rows (matches the repo and paper table).

Strict micro-F1/accuracy: correct predictions over all gold mentions (doc_id + start_pos join). This exposes missing gold coverage that the paper metric can hide.
