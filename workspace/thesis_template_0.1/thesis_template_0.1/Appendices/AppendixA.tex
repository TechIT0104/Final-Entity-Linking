\section{mReFinED MEWSLI-9 Reproduction: Key Fixes}
\begin{enumerate}
		\item CUDA compatibility: upgraded/downgraded PyTorch to match CUDA 12.8 (cu128).
		\item Tokenizer API: replaced deprecated \texttt{encode\_plus()} with \texttt{tokenizer()}.
		\item PEM data: added dict/list handling in candidate generation.
		\item Device placement: forced \texttt{--device cuda:0} and \texttt{CUDA\_VISIBLE\_DEVICES=0}.
		\item Dataset root: added \texttt{--datasets\_root} to avoid path breakage.
		\item Logging: enabled unbuffered output for live progress.
\end{enumerate}

\section{TR2016 Offset Validation (Key Insight)}
Offset corruption was detected in TR2016 mention files. A validation filter that compares extracted span text to annotated mention text improved recall on German from 1.54\% to 8.42\%.
