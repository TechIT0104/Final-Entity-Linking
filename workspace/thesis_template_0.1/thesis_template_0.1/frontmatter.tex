\begin{abstract}
\begin{spacing}{2}

\addchaptertocentry{\abstractname} % Add the abstract to the table of contents
This thesis presents an implementation-focused study of entity linking with an emphasis on the post-mid-semester phase: multilingual and historical EL. We briefly introduce the monolingual foundations (BLINK and MVD) and then focus on two post-mid-semester papers. First, we attempted to reproduce mReFinED and documented practical barriers: CUDA stack incompatibilities, tokenizer API breakages, PEM data format mismatches, dataset path issues, and evaluation discrepancies caused by corrupted TR2016 offsets. We successfully reproduced MEWSLI-9 evaluation and analyzed cross-script performance gaps.

Second, we implemented MHEL-LLaMo, an unsupervised ensemble that combines a multilingual bi-encoder for candidate retrieval with an instruction-tuned LLM for NIL prediction and candidate selection. We reproduced the paper's best settings across multiple historical benchmarks, validated scores against repository artifacts, and introduced robustness improvements in the retrieval and RAG pipeline. The thesis consolidates system design, experiments, error analyses, and reproducibility procedures in clear, reproducible form.


\end{spacing}
\end{abstract}
